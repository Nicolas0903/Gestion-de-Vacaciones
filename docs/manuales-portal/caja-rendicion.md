# Rendición presupuesto (depósitos) — Manual de uso

**Ruta:** `/caja-rendicion`  
**Acceso:** Restringido.

## Objetivo

Registrar **depósitos** y comprobantes de rendiciones de presupuesto ya **aprobadas** en el mes.

## Pasos

1. Abre el módulo desde **Rendiciones de caja**.
2. Lista rendiciones aprobadas pendientes de depósito.
3. Registra fecha de depósito, monto y adjunta comprobante.
4. Guarda; queda trazabilidad para cierre mensual.
