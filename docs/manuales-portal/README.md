## Áreas del portal (vista Inicio)

- **Mi espacio** — RRHH y documentos personales  
- **Operaciones y finanzas** — Gastos, caja, proveedores, cotizaciones  
- **Proyectos y análisis** — Horas, comisiones, Fabric  

La etiqueta **RESTRINGIDO** indica módulos que no todos los usuarios ven; el acceso se configura en **Administración de usuarios** (`modulos_portal`).
