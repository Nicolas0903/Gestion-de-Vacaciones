# Boletas de pago — Manual de uso

**Ruta colaborador:** `/boletas`  
**Gestión RRHH:** `/boletas/gestion` (enlace **Gestionar** en la tarjeta, solo admin/gestores)

## Colaborador

1. Entra a **Boletas de Pago**.
2. Lista de boletas por periodo; abre PDF o documento.
3. **Firmar** cuando esté habilitado (confirma lectura/aceptación según política Prayaga).
4. El portal puede mostrar pendientes de firma en **Para hoy**.

## Gestión

- Carga de boletas por empleado, mes y año.
- Asignación a colaboradores para consulta y firma.
