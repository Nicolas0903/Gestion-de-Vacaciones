# Permisos y descansos — Manual de uso

**Ruta:** `/permisos`

## Colaborador

1. Registra permiso o descanso médico con fechas y sustento si aplica.
2. Envía solicitud; queda pendiente de revisión.
3. Consulta historial y estado en la misma pantalla.

## Gestión / aprobación

- Usuarios con acceso a gestión ven **Permisos — Gestión** (`/permisos/gestion`).
- Aprueban o rechazan; el solicitante recibe notificación según configuración del sistema.

## Acceso desde el portal

Tarjeta **Vacaciones y Permisos** → elegir **Permisos y Descansos** si tienes ambos módulos.
