# Rendición de presupuesto — Manual de uso

**Ruta:** `/rendicion-presupuesto`  
**Gestión:** `/rendicion-presupuesto/gestion`  
**Acceso:** Restringido (admin o módulo activado por usuario).

## Colaborador autorizado

1. Registra rendición de gastos del área con detalle, montos y adjuntos.
2. Envía a flujo de aprobación.

## Aprobador

- Pantalla de gestión: revisa, aprueba o devuelve con observaciones.
- Tras aprobación puede vincularse al flujo de **Rendición presupuesto (caja)** para depósitos.

## Portal

Dentro de **Reintegros y Rendiciones** → **Rendición de Presupuesto** (si tienes acceso).
