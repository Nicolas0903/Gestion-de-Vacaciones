# Rendición caja chica — Manual de uso

**Ruta:** `/caja-chica`  
**Acceso:** Restringido (contabilidad / admin / cuentas autorizadas).

## Uso mensual

1. Selecciona mes y año del reporte.
2. Registra **ingresos manuales** y revisa **egresos** derivados de reintegros aprobados del periodo.
3. Cierra o exporta el reporte según botones disponibles.
4. Cuadra totales antes de enviar a contabilidad.

## Portal

**Rendiciones de caja** → **Rendición Caja Chica**.
