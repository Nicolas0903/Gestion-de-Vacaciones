# Consumo Microsoft Fabric — Manual de uso

**Ruta:** `/consumo-fabric`  
**Acceso:** Restringido (rol **admin** o módulo **consumo-fabric**).

## Objetivo

Cruzar el reporte **PAYG** de Microsoft Fabric con **montos mensuales por cliente** para facturación y control de consumo.

## Pestañas principales

| Pestaña | Uso |
|---------|-----|
| Reportes | Historial de cargas PAYG; abrir visualización y exportar Excel/PDF |
| Montos | Montos manuales por cliente / mes / año |
| Cargas | Listado técnico de archivos procesados |

## Subir reporte PAYG

1. **Subir archivo PAYG** (export de Microsoft).
2. El sistema procesa y muestra el **reporte visual** por cliente y uso.
3. Guarda la carga en el historial para consultas posteriores.

## Montos por cliente

1. Registra o edita **monto** y moneda para un **customer** y periodo (mes/año).
2. Los montos alimentan el cruce con el reporte PAYG del mismo periodo.
3. Guarda por periodo; revisa la tabla de periodos pendientes de monto.

## Exportar

Con un reporte abierto: **Exportar Excel** o **Exportar PDF** según botones disponibles.

## Portal

**Consumo Fabric** → **Ver detalle** (usuarios autorizados).
