# Reintegros / Reembolsos — Manual de uso

**Ruta colaborador:** `/reembolsos`  
**Gestión / aprobación:** `/reembolsos/gestion`

## Colaborador

1. **Nueva solicitud:** concepto, monto, adjunta comprobantes (PDF/imagen según pantalla).
2. Envía; sigue estados hasta aprobación contable/jefe según monto y reglas.
3. Consulta historial en la misma sección.

## Aprobador

- Entra a **Gestión de reembolsos**.
- Filtra pendientes; aprueba con observaciones o rechaza indicando motivo.

## Portal

Tarjeta **Reintegros y Rendiciones** → **Solicitud de Reintegro**.
