# Rendición presupuesto (depósitos) — Manual de usuario

**Ruta:** `/caja-rendicion`  
**Acceso:** **Restringido** — módulo **caja-rendicion**.

## 1. Propósito del documento

Registrar **depósitos bancarios** y comprobantes de **rendiciones de presupuesto ya aprobadas** en el mes.

## 2. Perfiles de usuario

Contabilidad / administración con módulo activo.

## 3. Acceso

Portal → **Rendiciones de caja** → **Rendición presupuesto (depósitos)** o ruta equivalente en la tarjeta.

## 4. Procedimiento

1. Abra el listado de rendiciones **aprobadas** pendientes de depósito.
2. Seleccione la rendición.
3. Registre **fecha de depósito**, **monto** y adjunte **comprobante** (voucher bancario).
4. **Guarde**; queda trazabilidad para cierre mensual con **Caja chica** y contabilidad.

## 5. Relación con otros módulos

| Módulo previo | Rol |
|---------------|-----|
| Rendición de presupuesto | Genera rendición aprobada |
| Caja chica | Consolidación mensual |

## Soporte

Módulo **Caja rendición**, ID rendición y captura.
