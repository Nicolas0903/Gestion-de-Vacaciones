# Rendición caja chica — Manual de usuario

**Ruta:** `/caja-chica`  
**Acceso:** **Restringido** — contabilidad / admin / cuentas con módulo **caja-chica**.

## 1. Propósito del documento

Armar el **reporte mensual de caja chica**: **ingresos** registrados manualmente y **egresos** derivados de reintegros aprobados del periodo.

## 2. Perfiles de usuario

Personal de **contabilidad** o **administración** con módulo activo.

## 3. Acceso

Portal → **Rendiciones de caja** → **Rendición caja chica**.

## 4. Procedimiento mensual

1. Seleccione **mes** y **año**.
2. Registre **ingresos manuales** (fondo, reposiciones, etc.).
3. Revise **egresos** importados o listados desde reintegros **aprobados** del mes (fecha de documento del periodo).
4. Cuadre **totales** (saldo, ingresos, egresos).
5. Exporte o cierre según botones disponibles antes de enviar a contabilidad.

## 5. Buenas prácticas

- No cierre el mes hasta conciliar con reintegros pendientes de aprobación.
- Guarde respaldo del reporte exportado según política interna.

## Soporte

Módulo **Caja chica**, mes/año y captura de totales.
