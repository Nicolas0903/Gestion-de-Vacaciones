# Vacaciones — Manual de usuario

**Ruta en el portal:** `/vacaciones` (subrutas: dashboard, mis-solicitudes, nueva-solicitud, calendario, aprobaciones)  
**Acceso:** Módulo **vacaciones** (habitualmente todo el personal).

## 1. Propósito del documento

Explicar cómo **solicitar días de vacaciones**, **consultar saldos**, usar el **calendario** y, para aprobadores, gestionar la **bandeja de aprobaciones**.

## 2. Perfiles de usuario

| Perfil | Funciones |
|--------|-----------|
| Colaborador | Dashboard, nueva solicitud, mis solicitudes, calendario, vacaciones ganadas |
| Jefe / contadora / admin | Aprobaciones, estado de vacaciones (según rol) |
| RRHH | Estado de vacaciones, carga de periodos (admin/contadora) |

## 3. Acceso al módulo

1. Portal → tarjeta **Vacaciones y Permisos** → **Vacaciones** (o menú lateral del layout de vacaciones).
2. Use **Guía rápida / Manual completo / PDF** arriba del contenido.

## 4. Colaborador — flujo típico

1. **Dashboard:** revise días pendientes, solicitudes en curso y resumen.
2. **Vacaciones ganadas:** periodos y saldos registrados por administración.
3. **Nueva solicitud:** fechas de inicio/fin, tipo, comentarios → **Enviar**.
4. **Mis solicitudes:** estados y detalle de cada pedido.
5. **Calendario:** vista de vacaciones del equipo (según permisos).

## 5. Estados de solicitud

| Estado | Significado |
|--------|-------------|
| Borrador / pendiente | En flujo de revisión |
| Pendiente jefe | Espera aprobación del jefe directo |
| Pendiente contadora | Espera validación RRHH/contabilidad |
| Aprobada | Confirmada; aparece en calendario |
| Rechazada | No procede; revise observaciones |

## 6. Aprobaciones (`/vacaciones/aprobaciones`)

Solo roles autorizados (jefe, contadora, admin):

1. Entre a **Aprobaciones** en el menú lateral.
2. Revise cada solicitud (fechas, saldo, comentarios).
3. **Apruebe** o **rechace** con observaciones.
4. Desde **Inicio**, el KPI **Aprobaciones pendientes** puede redirigir a la bandeja correspondiente.

## 7. Estado de vacaciones (gerencial)

Ruta `/vacaciones/estado-vacaciones` (admin/contadora): vista consolidada de saldos y periodos del personal.

## 8. Consejos

- Verifique saldo en dashboard antes de pedir bloques largos de días.
- No duplique solicitudes solapadas; cancele o espere resolución de la anterior.
- Las solicitudes activas pueden reflejarse en KPIs del portal Inicio.
