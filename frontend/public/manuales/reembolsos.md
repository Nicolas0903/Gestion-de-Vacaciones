# Reintegros / reembolsos — Manual de usuario

**Ruta colaborador:** `/reembolsos`  
**Ruta gestión:** `/reembolsos/gestion`  
**Acceso:** Módulo **reembolsos** (colaborador); aprobadores según rol.

## 1. Propósito del documento

Registrar **solicitudes de reintegro** de gastos con comprobantes y dar seguimiento hasta **aprobación** o **rechazo**.

## 2. Perfiles de usuario

| Perfil | Pantalla |
|--------|----------|
| Colaborador | Nueva solicitud e historial |
| Aprobador / admin | Gestión de reembolsos |

## 3. Acceso

Portal → **Reintegros y Rendiciones** → **Solicitud de reintegro**.

## 4. Nueva solicitud (colaborador)

1. **Fecha**, **concepto** y **monto**.
2. Indique si tiene **comprobante** y adjunte archivo (PDF/imagen; respete tamaño máximo indicado en pantalla).
3. **Método de pago:** Yape, Plin o transferencia — complete celular, nombre o cuenta según método.
4. **RUC** y **N° de documento:** use el icono **?** junto al campo para ver ejemplo de factura.
5. Envíe; estado inicial **Pendiente**.

## 5. Estados

| Estado | Significado |
|--------|-------------|
| Pendiente | En revisión |
| Aprobado | Procesado para pago / contabilidad |
| Rechazado | No procede; revise motivo |
| Observado | Requiere corrección o información |

## 6. Gestión (`/reembolsos/gestion`)

1. Filtre **pendientes** u otros estados.
2. Revise comprobante, montos y datos tributarios.
3. **Apruebe**, **observe** o **rechace** con comentarios.
4. Puede editar campos administrativos según permisos (modal de edición).

## 7. Buenas prácticas

- Comprobante legible, RUC y número alineados al PDF.
- Un reintegro por comprobante cuando la política lo indique.

---

## Soporte

Módulo **Reembolsos**, ID de solicitud y captura.
