# Consumo Microsoft Fabric — Manual de usuario

**Ruta:** `/consumo-fabric`  
**Acceso:** **Restringido** — admin o módulo **consumo-fabric**.

## 1. Propósito del documento

Cruzar el reporte **PAYG** (pay-as-you-go) de Microsoft Fabric con **montos mensuales facturados por cliente**.

## 2. Perfiles de usuario

Administración, finanzas o analítica autorizada.

## 3. Acceso

Portal → **Consumo Fabric** → **Ver detalle**.

## 4. Pestañas

| Pestaña | Función |
|---------|---------|
| Reportes | Historial de cargas PAYG; visualización |
| Montos | Registro manual monto/mes/cliente |
| Cargas | Listado técnico de archivos procesados |

## 5. Subir reporte PAYG

1. **Subir archivo** exportado desde Microsoft (PAYG).
2. El sistema procesa y muestra **reporte visual** por cliente/consumo.
3. La carga queda en historial para consultas posteriores.

## 6. Montos por cliente

1. Seleccione **customer**, **mes** y **año**.
2. Ingrese **monto** y **moneda** (p. ej. US$).
3. Guarde; el cruce con PAYG del mismo periodo alimenta reportes y exportaciones.

## 7. Exportar

Con un reporte abierto: **Exportar Excel** o **Exportar PDF** (según botones visibles).

---

## Soporte

Módulo **Consumo Fabric**, ID de carga y periodo.
